# Resume Placeholder

This directory should contain your CV file named `CV.pdf`.

## How to add your CV:

1. Export your CV as a PDF
2. Name it `CV.pdf`
3. Place it in this `public/` folder
4. The download button in the header will automatically link to `/CV.pdf`

## Alternative: Use a third-party service

You can also link to your CV hosted on:
- LinkedIn (export as PDF)
- Google Docs (Share → Download as PDF link)
- Dropbox or Google Drive (share link)

To use an external link, update the `SiteHeader` component's CV button to point to your external URL.
